# Projeto

## Nome

Kélia Priscila - Desenvolvimento de sites e sistemas web

---

## Descrição

Atuar como um designer de UI/UX, desenvolvedor web sênior e estrategista de conteúdo para projetar e desenvolver o site profissional de Kélia Priscila, profissional de tecnologia especializada em desenvolvimento de sites e criação de sistemas web.

O site servirá para divulgar trabalhos acadêmicos e projetos profissionais, construir autoridade técnica e captar novos clientes por meio da geração de leads na página de contato.

---

## Público-alvo

O sistema é destinado inicialmente a pessoas que necessitam de serviços para desenvolvimento de sites web, sistemas web e suporte e manutenção dos mesmos.
---

## Objetivo

O sistema deve proporcionar uma forma simples, organizada e visual de forma organização e atraente para o público-alvo.
